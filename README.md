 🏥 Disease Prediction System using Machine Learning

A Machine Learning based healthcare analytics system that predicts diseases based on patient symptoms and medical parameters. The project also includes an interactive Streamlit dashboard for real-time patient analysis, risk assessment, and healthcare recommendations.

## 📌 Project Objective

The main objective of this project is to:

- Predict diseases based on patient symptoms
- Assist in early diagnosis
- Support healthcare decision-making
- Reduce diagnostic time
- Provide risk level analysis
- Generate patient healthcare reports

---

## 🚀 Features

- Disease prediction using Machine Learning
- Interactive healthcare dashboard
- Patient symptom recording
- Confidence score calculation
- Risk level analysis
- Doctor recommendation system
- Patient history tracking
- Downloadable healthcare reports

```bash

```

```bash
pip install pandas numpy scikit-learn matplotlib streamlit
```

### Run dashboard

```bash
streamlit run app.py
```
